# Navneet Music App

A SoundBound-style Android music application built from scratch.

## Current milestone

- Kotlin + Jetpack Compose
- Material 3 dark UI foundation
- Media3 / ExoPlayer local playback
- Local MediaStore music scanning
- Mini player
- Search and library UI
- Modular provider/extension interfaces
- No fake/default audio in the production playback path

## Next milestones

1. MediaSession/background playback service
2. Persistent library, favorites, history and playlists
3. Extension loading/management
4. Legitimate online provider integration
5. Full player, queue, lyrics and downloads
6. Premium SoundBound-style UI/UX
